# 🎾 テニススコア記録アプリ

スマートフォンでもPCでもブラウザだけで動作する、テニスの試合スコア記録アプリです。
シングルス・ダブルス両対応、試合の振り返り、PDFレポート出力ができます。

---

## 📱 使い方

### 試合中
1. **シングルス / ダブルス** を選択
2. プレイヤー名を入力（ダブルスはペアの名前も）
3. **大会名・コート** をメモ欄に記入（任意）
4. どちらのチームから **サーブを開始するか** を選択
5. ポイントが入るたびに **「▲ 〇〇 得点」** ボタンをタップ
6. デュース・アドバンテージ・タイブレーク・セット終了は自動で判定されます

### スコアを間違えてしまったとき
- **「↶ 戻す」** ボタンで1ポイントずつ戻せます
- 得点ボタンを押した直後は画面下に **取り消しトースト** が出るので、間違えたらすぐ取り消せます
- **「✎ 修正モード」** をタップすると直近10ポイントの一覧が出ます。間違ったポイントだけを個別に削除できます

### 試合終了後
- **「💾 戦績に保存」** で記録がブラウザに保存されます
- **「📄 PDFで出力」** で試合レポートを印刷ダイアログ経由でPDF化できます（ペアの方に渡せます）

### 戦績タブ
- 過去の試合一覧を確認
- 試合をタップすると詳細（ポイント推移グラフ、サーバー別獲得率、全ポイント詳細）が見られます
- 各試合からもPDF出力が可能

## 🌐 GitHub Pagesで公開する手順

### はじめての方向け

1. **GitHubでリポジトリを作る**
   - GitHub にログイン → 右上の「+」→「New repository」
   - リポジトリ名: 例 `tennis-score`（自由）
   - 「Public」を選択
   - 「Create repository」をクリック

2. **index.html をアップロードする**
   - 作成したリポジトリの「Add file」→「Upload files」
   - `index.html` をドラッグ＆ドロップ
   - 「Commit changes」をクリック

3. **GitHub Pages を有効化する**
   - リポジトリの「Settings」タブ
   - 左メニュー「Pages」をクリック
   - 「Source」で「Deploy from a branch」、Branchを「main」、フォルダを「/ (root)」にして「Save」
   - 数分待つと、画面上部に公開URLが表示されます  
     例: `https://あなたのユーザー名.github.io/tennis-score/`

4. **完成！**
   - そのURLをペアの方や連盟の方に共有すれば、誰でもブラウザから使えます
   - スマホのホーム画面に追加すれば、アプリのように使えます（Safariなら「共有」→「ホーム画面に追加」）

### スコア記録の保存場所について
- 戦績は **そのブラウザ・端末のlocalStorage** に保存されます
- 別の端末では別々の戦績になります（同期はされません）
- ブラウザのデータを削除すると消えるので、大事な記録はPDFで残しておくのがおすすめです

## 🔧 カスタマイズしたいとき

`index.html` は1ファイルで完結しています。テキストエディタで開いて、色やラベルを変えたり、機能を追加したりできます。

主な調整箇所：
- 上部の `<style>` でCSSを変更
- `POINTS` 定数や `freshState()` 関数で初期値を調整
- `renderMatchDetail()` でPDFの内容をカスタマイズ

---

## 📋 対応ルール

- 1セット / 3セット / 5セットマッチ
- タイブレーク（オン/オフ切替可）
- ノーアドバンテージ方式（オン/オフ切替可）
- ダブルスのサーブ順自動ローテーション
- タイブレーク中のサーブ交代（1ポイント目→以降2ポイントごと）
